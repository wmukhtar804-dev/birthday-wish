# Wishora - Personalized Birthday Experience

Wishora is a premium, fully responsive birthday experience website that turns user input into a relationship-aware celebration.

## Features
- Cinematic landing page with animated gradient ambience and floating particles
- 4-step creation wizard with progress tracking
- Relationship-specific personalization for tone, visuals, and messaging
- Language options: English, Urdu, Roman Urdu, and mixed mode
- Photo memories workflow with preview, cover selection, reordering, captions, and removal
- Dynamic final experience view with themed sections and music vibe suggestions

## Tech
- HTML
- CSS
- Vanilla JavaScript

## Run locally
Open `index.html` in a browser.
