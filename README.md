# Wishora - Personalized Birthday Experience

Wishora is a premium, responsive birthday experience generator built with React + Vite.

## Features

- Cinematic landing page with animated gradient visuals and preview cards
- 4-step creation wizard with progress tracking
- Relationship-aware personalization engine (tone, copy, and visual direction)
- Multi-photo memories with preview, remove, reorder, cover selection, and captions
- Experience selection with final summary and generated interactive celebration view
- Language preference support: English, Urdu, Roman Urdu, and Mixed style

## Run locally

```bash
npm install
npm run dev
```

## Validate

```bash
npm run lint
npm run build
```
